# PYDOOM — 2.5D шутер в духе DOOM (1993) на Python + pygame

Играбельный псевдо-3D шутер с raycasting-рендером. **Вся графика и все звуки
генерируются процедурно** (numpy / pygame.Surface) — внешних ресурсов нет.

## Запуск

```bash
python main.py
```

Требования: `pygame`, `numpy` (`pip install pygame numpy`).

### Сборка .exe

Готовый исполняемый файл: **`dist\PYDOOM.exe`** (single-file, без консоли —
Python не нужен, все ресурсы уже внутри).

Пересборка после изменений кода:

```bash
build_exe.bat
```
или вручную: `pip install pyinstaller` → `python -m PyInstaller --onefile --windowed --clean --name PYDOOM main.py`

Некоторые антивирусы ругаются на onefile-EXE от PyInstaller (ложное
срабатывание) — при проблемах добавьте папку в исключения.

## Управление

| Клавиша          | Действие                       |
|------------------|--------------------------------|
| WASD / стрелки   | движение + стрейф              |
| Мышь             | обзор (курсор захвачен окном)  |
| ЛКМ / Ctrl       | стрельба / бензопила           |
| 1 / 2 / 3 / 4    | пистолет / дробовик / бензопила / плазмаган |
| Tab              | мини-карта вкл/выкл            |
| M                | музыка вкл/выкл                |
| P                | пауза                          |
| R                | перезапуск уровня              |
| Esc              | меню / выход                   |

## Геймплей

- **4 оружия**: пистолет, дробовик, **бензопила** (слот 3, без патронов,
  непрерывный урон вблизи) и **плазмаган** (слот 4, снаряды, ячейки).
- **Босс-кибердемон каждые 5 уровней**: огромный, не вздрагивает от выстрелов,
  стреляет ракетами; EXIT-переключатель заперт (красный крест), пока он жив.
  Убей — переключатель оживёт. Полоса здоровья босса сверху экрана.
- **Бесконечные уровни**: уровень 1 — авторская карта; каждый следующий
  генерируется процедурно (`levelgen.py`: комнаты + коридоры + петли),
  макет уровня детерминирован по seed (R перезапускает тот же уровень),
  сложность растёт: больше комнат и врагов, доля солдат и характеристики.
- 2 рядовых врага: **имп** (файерболы + когти) и **бывший солдат** (стреляет),
  ИИ: сон → преследование по прямой видимости/шуму → атака, анимации ходьбы,
  атаки, боли и смерти; трупы остаются на уровне.
- Аптечки, патроны, дробь и ячейки; стрельба будит врагов в радиусе.
- Текстурированные стены/пол/потолок, затухание света с расстоянием (fog),
  затенение боковых граней стен, факелы.
- Классический DOOM-HUD: красные цифры, лицо десника (получает кровь и
  ухмыляется при стрельбе), ARMS 1-4, счётчик фрагов и уровня, мини-карта.
- Главное меню с огнём DOOM, экраны Game Over и Level Cleared.

## Модули

| Файл                | Назначение                                              |
|---------------------|---------------------------------------------------------|
| `main.py`           | состояния игры, меню с DOOM-огнём, ввод, главный цикл   |
| `settings.py`       | все константы (окно, камера, игрок, оружие, враги)      |
| `map.py`            | разбор карты, DDA-лучи, коллизии со скольжением         |
| `levelgen.py`       | бесконечная процедурная генерация уровней               |
| `textures.py`       | процедурные текстуры стен/пола/потолка и спрайтов       |
| `raycasting.py`     | векторизованный raycaster (numpy) + z-buffer            |
| `object_renderer.py`| проекция спрайтов, оружие, мини-карта, вспышки          |
| `sprite_object.py`  | базовый спрайт, аптечки/патроны, факелы                 |
| `npc.py`            | имп, солдат, файербол, взрыв + ИИ                       |
| `weapon.py`         | пистолет и дробовик с анимацией и hitscan-стрельбой     |
| `sound.py`          | процедурные 8-бит звуки + зацикленный риф (numpy)       |
| `hud.py`            | статус-бар: цифры, лицо, ARMS                           |
| `test_smoke.py`     | headless-тест: запуск, стрельба, ИИ, состояния          |

Проверка без окна: `python test_smoke.py`
